## Реализованные системы

### 1. Настройки (Settings)
- **SettingsManager** — синглтон, PlayerPrefs. Разрешение, fullscreen, VSync, чувствительность мыши, яркость, гамма, дальтонизм, FPS-счётчик
- **SettingsUI** — дропдауны/слайдеры для всех настроек
- **DisplayEffectController** — Canvas overlay: яркость (альфа), гамма (цвет), дальтонизм (полупрозрачный overlay)
- **FPSDisplay** — 4 позиции углов, автосоздание
- **CinemachineSensitivity** — модифицирует Gain/LegacyGain у InputAxisController
- **CameraController.sensitivityMultiplier** — множитель чувствительности

### 2. Босс-арена (BossArena)
- Стены управляются через `Collider.enabled` (не SetActive)
- Триггер входа активирует стены, смерть босса — деактивирует
- Не блокирует вход до входа в триггер

### 3. Стамина (Stamina)
- **Stamina.cs** — затраты: бег 15/с, атака 20, перекат 15, прыжок 10. Реген 30/с после 0.5с задержки
- **StaminaUI** — Filled Image, lazy-connect к Stamina
- **PlayerController** — интеграция: `HasStamina()` проверка, блокировка бега на 1с при истощении

### 4. Здоровье (Health)
- `baseMaxHealth`, `SetMaxHealth()` — при увеличении max восполняет разницу
- `OnModifyIncomingDamage` — `Func<float,float>` для защиты
- `TakeDamage` применяет модификатор защиты

### 5. Оружие (Weapon)
- `damage = base + PlayerStats.DamageBonus` (Сила)
- Hitbox через Animation Events: EnableHitbox/DisableHitbox
- Защита от множественных попаданий за атаку

### 6. Валюта и прокачка (Currency & Level-Up)

#### CurrencyUI
- Счётчик душ, правый верхний угол, полупрозрачный тёмный фон, светло-оранжевый текст
- Создаёт свой `DontDestroyOnLoad` Canvas, sortingOrder=50
- **Polling** — каждый кадр читает `PlayerStats.Instance.Currency`, анимирует плавный счёт
- Никаких подписок на события — работает всегда, независимо

#### LevelUpMenu
- Статический `Show()`/`Hide()` — создаёт свой Canvas + GraphicRaycaster + EventSystem
- 6 статов с ◀/▶, описание бонуса, цена прокачки
- `8 → 9` жёлтым при планировании, справа стоимость
- Кнопки: Подтвердить / Сброс / Закрыть
- При подтверждении: снимает души → повышает стат → применяет бонус → сохраняет в PlayerPrefs
- Ставит `Time.timeScale=0`, отключает PlayerController, разблокирует курсор

#### LevelUpShrine
- Только триггер + подсказка "Нажмите E для молитвы"
- E → `LevelUpMenu.Show()`, Escape/E → `LevelUpMenu.Hide()`
- Настройки: радиус, клавиша, текст подсказки, опциональный promptPanel

#### PlayerStats
- 6 статов (Сила/Ловкость/Здоровье/Сопротивление/Защита/Удача), стартовый уровень 8
- Soul Level = сумма всех статов (48 на старте)
- Формула цены: `BaseCost × (1 + 8% × душLevelsAbove48) × (1 + 3% × statLevelsAbove8)`
- `LevelUpStat()` — снимает валюту, повышает стат, сохраняет, применяет бонусы
- `AddCurrency()` — добавляет + LuckBonus
- `ApplyStatBonuses()` — обновляет Health.SetMaxHealth и Stamina.SetMaxStamina
- `SubscribePlayerDefense()` — подписывает ApplyDefense на Health.OnModifyIncomingDamage
- DontDestroyOnLoad синглтон, создаётся в MainMenu сцене

## Связь статов → эффекты

| Стат | Бонус за уровень выше 8 | Где применяется |
|------|--------------------------|-----------------|
| Сила | +2 урона | Weapon.cs: `totalDamage += PlayerStats.Instance.DamageBonus` |
| Ловкость | +10 стамины | Stamina.cs: `SetMaxStamina()` из PlayerStats.ApplyStatBonuses |
| Здоровье | +10 HP (и восстановление) | Health.cs: `SetMaxHealth()` — восполняет разницу |
| Сопротивление | Пока не влияет | — |
| Защита | -1 входящего урона | Health.cs: `OnModifyIncomingDamage` → `ApplyDefense()` |
| Удача | +10 душ за убийство | PlayerStats.AddCurrency: `amount + LuckBonus` |

## Важные детали (чтобы не сломать)

1. **PlayerStats** — DontDestroyOnLoad синглтон из MainMenu. Все остальные системы зависят от `PlayerStats.Instance`
2. **CurrencyUI** — polling, не события. Если добавить `OnCurrencyChanged` логику — не нужно, она уже не используется счётчиком
3. **LevelUpMenu** — сам создаёт EventSystem если его нет. Не компонент на объекте в сцене — вызывается через `LevelUpMenu.Show()`
4. **LevelUpShrine** — не создаёт панель, не управляет UI. Только триггер → вызывает статические методы LevelUpMenu
5. **Health.SetMaxHealth** — при увеличении max восполняет разницу (бесплатное лечение при прокачке Здоровья — это задумано)
6. **Stamina.SetMaxStamina** — аналогично, восполняет разницу при увеличении
7. **PlayerPrefs** — ключи: `PS_Currency`, `PS_Stat_0`...`PS_Stat_5`. Настройки: `Settings_Resolution` и т.д.
